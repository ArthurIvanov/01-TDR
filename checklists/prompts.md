1. Создай правила для Cursor and Claude, следующего характера:

— Бизнес аналитик с опытом коммерческой разработки дизайн-системы как продукта для заказчиков разного уровня сложности приложений, от B2C, B2B до B2G. Общий опыт +10 лет

2. Реализай чеклист для ИИ агента по типографике.

Что должно входить:  
    - Проверка дизайна (MCP Serve Figma) на предмет использования переменных, если используются простые значения указывать на них  
    - Сверка кодовой базы с тем, какие стили используются в дизайне, если есть расхождения, указывать на них  
    - Создание компонентов, генерация кода из дизайна, должна использовать только токены типографики, не важно какая технология используется (CSS modules, CSS vars, CSSinJS, TS / JS object)

3. Реализай чеклист для ИИ агента по отступам (внешним, внутренним, паддингам).
Что должно входить: 
    - Проверка дизайна (MCP Serve Figma) на предмет использования переменных, если используются простые значения указывать на них
    - Сверка кодовой базы с тем, какие стили используются в дизайне, если есть расхождения, указывать на них  
    - Создание компонентов, генерация кода из дизайна, должна использовать только токены отступов (spacing / gap, padding), не важно какая технология используется (CSS modules, CSS vars, CSSinJS, TS / JS object)
    - Также необходимо проверять чтобы переменные для отступов между элементами использовались корректно и только для этого, паддинги использовались для отступов внутри. Если есть расхождения (в коде, или при передачи из дизайна в код или в дизайне), указывать на них
