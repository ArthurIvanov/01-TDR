# Веб-доступность (WCAG): общие рекомендации

Версия 1.3 · draft · Целевой уровень: **WCAG 2.2 AA** · Платформа: только web

Документы набора: **общие** (этот файл) · [для дизайнера](a11y-design.md) · [для разработчика](a11y-development.md) · [правила для ИИ-агентов](a11y-agent-rules.md)

**Как читать:** `P0` — блокер релиза, `P1` — обязательно для AA, исправить в спринте. В скобках — критерий WCAG. ID (`G-`, `D-`, `R-`) стабильны: ссылайтесь на них в задачах и PR.

---

## Нормативная база РФ

- **181-ФЗ «О социальной защите инвалидов», ст. 14** — доступ инвалидов к информации.
- **ГОСТ Р 52872-2019** — требования доступности интернет-ресурсов и интерфейсов; основная ссылка в ТЗ для B2G.
- **ГОСТ Р ИСО/МЭК 40500-2013** — идентичен WCAG 2.0.
- **8-ФЗ** и ведомственные требования — для сайтов госорганов.

**Решение:** проектируем под **WCAG 2.2 AA** для всех сегментов. Это перекрывает WCAG 2.0 и 2.1 AA, на которые опираются российские нормы. AAA в обязательные требования не входит. Вместо отдельной версии для слабовидящих — адаптивная тема высокого контраста.

| Сегмент | Акцент |
|---|---|
| B2C | AA, не ухудшать скорость и конверсию |
| B2B | AA, сложные формы и таблицы, контраст white-label тем |
| B2G | AA **обязательно**, документация, доступные документы (PDF) |

## Процесс

- [ ] **G-01 P0** Уровень WCAG 2.2 AA записан в ТЗ и Definition of Done.
- [ ] **G-02 P0** Компонент получает статус `ready` только после прохождения чеклистов дизайна и разработки.
- [ ] **G-03 P1** a11y-критерии входят в acceptance criteria задачи (не «сделать доступно»).
- [ ] **G-04 P1** В документации компонента есть блок Accessibility: роль, клавиши, ARIA, фокус.
- [ ] **G-05 P1** Проверка двух видов: автоматика в CI (eslint-plugin-jsx-a11y, axe) **и** вручную (клавиатура + скринридер). Автоматика не находит всех проблем.
- [ ] **G-06 P1** Изменение a11y-поведения (роль, порядок фокуса, клавиши) — breaking change в changelog.

## Контент (дизайнер, редактор, разработчик)

- [ ] **G-07 P1** Язык `ru` задан, смена языка в тексте размечена (3.1.1, 3.1.2). Ссылки и кнопки понятны вне контекста: не «Здесь», «Подробнее» (2.4.4).
- [ ] **G-08 P1** Для B2G: документы PDF и DOC размечены (теги, заголовки, язык) либо есть HTML-версия; сканы без текстового слоя недопустимы.

## Быстрая ручная проверка (перед релизом)

1. **Клавиатура:** Tab, Shift+Tab, Enter, Space, Esc, стрелки; фокус виден, ловушек нет.
2. **Масштаб:** 200% и ширина 320px; нет потери контента и горизонтального скролла.
3. **Скринридер:** NVDA + Firefox/Chrome (Windows), VoiceOver + Safari (macOS/iOS); у элементов понятны имя, роль, состояние.
4. **Контраст и цвет:** плагин `01-TDR-a11y-contrast-checker`, ч/б режим, тема высокого контраста.
5. **Анимации:** включён `prefers-reduced-motion`.
