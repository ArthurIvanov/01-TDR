# Веб-доступность (WCAG): для дизайнера

Целевой уровень: **WCAG 2.2 AA** · [Общие рекомендации](a11y-general.md) · [Для разработчика](a11y-development.md)

`P0` — блокер релиза, `P1` — обязательно для AA. В скобках — критерий WCAG.

- **Часть 1** — требования к любому дизайну, независимо от инструмента.
- **Часть 2** — как выполнить их в Figma.

---

## Часть 1. Общие требования к дизайну

### Пороги контраста

| Что | Минимум |
|---|---|
| Обычный текст | **4.5:1** (1.4.3) |
| Крупный текст (≥ 24px или ≥ 18.66px bold) | **3:1** (1.4.3) |
| Границы полей, иконки, индикаторы, фокус | **3:1** (1.4.11) |

### Структура и содержание

- [ ] **D-01 P0** Один H1 на экран, уровни заголовков без пропусков; уровень указан в спецификации, а не выводится из размера (1.3.1, 2.4.6).
- [ ] **D-02 P0** Отмечены ориентиры: header, nav, main, footer; есть skip link (1.3.1, 2.4.1).
- [ ] **D-03 P0** Визуальный порядок = логический; нетривиальный порядок фокуса описан (1.3.2, 2.4.3).
- [ ] **D-04 P1** Повторяющиеся элементы (меню, поиск, помощь) на всех экранах стоят в одном месте и названы одинаково (3.2.3, 3.2.4, 3.2.6).

### Цвет

- [ ] **D-05 P0** Контраст проверен по порогам выше для **всех состояний** (default, hover, focus, error, disabled) во **всех темах** (light, dark, white-label).
- [ ] **D-06 P0** Смысл не передаётся только цветом: ошибка = цвет + иконка + текст; ссылка в тексте подчёркнута (1.4.1).
- [ ] **D-07 P0** Есть адаптивная **тема высокого контраста** (вместо отдельной версии для слабовидящих): все компоненты и состояния проверены в ней, контраст текста ≥ 7:1 (рекомендация, уровень AAA).

### Текст и масштаб

- [ ] **D-09 P0** Макет выдерживает 200% текста и reflow на 320px без горизонтального скролла (1.4.4, 1.4.10).
- [ ] **D-10 P1** Контейнеры не ломаются при увеличенных интервалах: межстрочный 1.5, абзац 2×, буквы 0.12em, слова 0.16em (1.4.12).
- [ ] **D-11 P1** Текст не вшит в изображения, кроме логотипов (1.4.5).

### Фокус и интерактив

- [ ] **D-12 P0** Нарисован focus-state для каждого интерактивного компонента: рамка ≥ 2px, контраст ≥ 3:1, не перекрыт sticky-элементами (2.4.7, 2.4.11).
- [ ] **D-13 P0** Размер цели нажатия ≥ **24×24px** (2.5.8). Для мобильных и основных действий рекомендуется 44px.
- [ ] **D-14 P0** У drag-and-drop и слайдеров есть альтернатива в одно нажатие (2.5.7).
- [ ] **D-15 P1** Tooltip и popover закрываются по Esc, не исчезают при наведении на них, показываются и по hover, и по focus (1.4.13).

### Формы

- [ ] **D-16 P0** У каждого поля видимая постоянная метка; placeholder не заменяет label (1.3.1, 3.3.2).
- [ ] **D-17 P0** Обязательные поля отмечены текстом или знаком с пояснением, не только цветом (3.3.2).
- [ ] **D-18 P0** Нарисованы состояния ошибки: текст рядом с полем + иконка; для длинных форм — сводка ошибок. Текст ошибки говорит, что исправить (3.3.1, 3.3.3).
- [ ] **D-19 P1** Подсказки по формату видны до ввода. Не требуется повторный ввод уже введённых данных (3.3.7).
- [ ] **D-20 P1** Для юридически и финансово значимых действий есть шаг подтверждения или отмена (3.3.4).

### Изображения и медиа

- [ ] **D-21 P0** Для значимых изображений и иконок указан alt; декоративные помечены как декоративные. У icon-only кнопок задано название (1.1.1).
- [ ] **D-22 P0** Видео: субтитры; аудио: транскрипт (1.2.1, 1.2.2).
- [ ] **D-23 P0** Автоплей, карусели и анимации можно остановить; нет вспышек чаще 3 раз в секунду (2.2.2, 2.3.1).

## Часть 2. Применимо в Figma

- [ ] **D-08 P1** Цвета, размеры целей и отступы заданы только **переменными (variables)**, без хардкода. Допустимые пары text/surface зафиксированы в документации DS. Тема высокого контраста — отдельный режим переменных (D-07).
- [ ] **D-24 P1** У компонента есть a11y-аннотации (Annotation / Dev Mode): роль, accessible name, клавиатурный сценарий, порядок фокуса, уровень заголовка, alt.
- [ ] **D-25 P1** К handoff приложен отчёт плагина `01-TDR-a11y-contrast-checker`.
