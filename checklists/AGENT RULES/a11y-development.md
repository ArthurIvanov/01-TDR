# Веб-доступность (WCAG): для разработчика

Целевой уровень: **WCAG 2.2 AA** · [Общие рекомендации](a11y-general.md) · [Для дизайнера](a11y-design.md)

`P0` — блокер релиза, `P1` — обязательно для AA. В скобках — критерий WCAG.

- **Часть 1** — требования к любому веб-коду (HTML, CSS, ARIA).
- **Часть 2** — то, что специфично для React и нашего стека.

---

## Часть 1. Общие требования к коду

### Семантика и ARIA

- [ ] **R-01 P0** Нативные элементы вместо кастомных: `button`, `a[href]`, `input`, `label`, `nav`, `main`, `dialog`, `table`, `ul`. Запрещён `<div onClick>` (4.1.2).
- [ ] **R-03 P0** Ориентиры `header`, `nav[aria-label]`, один `main`, `footer`; `lang` на `<html>`; `<title>` отражает текущую страницу (2.4.1, 2.4.2, 3.1.1).
- [ ] **R-04 P0** Сначала HTML, потом ARIA. Кастомные виджеты строятся по [ARIA APG](https://www.w3.org/WAI/ARIA/apg/): роль + состояния + клавиши.
- [ ] **R-05 P0** У каждого интерактивного элемента есть accessible name; он содержит видимый текст (2.5.3, 4.1.2).
- [ ] **R-06 P0** Состояния синхронны со state: `aria-expanded`, `aria-selected`, `aria-checked`, `aria-pressed`, `aria-current`, `aria-invalid`.
- [ ] **R-07 P1** `aria-hidden` не ставится на фокусируемые элементы. Декоративные SVG: `aria-hidden="true"`.

### Клавиатура и фокус

- [ ] **R-09 P0** Весь функционал доступен с клавиатуры, ловушек нет (2.1.1, 2.1.2).
- [ ] **R-10 P0** Порядок Tab логичен; `tabindex > 0` запрещён (2.4.3).
- [ ] **R-11 P0** Видимый `:focus-visible` из токенов. `outline: none` без замены запрещён (2.4.7).
- [ ] **R-14 P1** Фокус не теряется при удалении элемента или смене состояния. Skip link — первый фокусируемый элемент.

### Формы и статусы

- [ ] **R-15 P0** `<label for>` на каждое поле; группы — `fieldset/legend` (1.3.1, 3.3.2).
- [ ] **R-16 P0** Ошибки: `aria-invalid` + `aria-describedby`; при submit фокус на сводку или первое невалидное поле (3.3.1).
- [ ] **R-17 P0** Корректные `type`, `required`, `autocomplete` (1.3.5). Вставка в поле пароля не блокируется (3.3.8).
- [ ] **R-18 P1** Динамические статусы («Сохранено», ошибка загрузки) — через live region `role="status"` или `role="alert"`; контейнер есть в DOM заранее (4.1.3). Toast не забирает фокус.
- [ ] **R-19 P1** Состояние загрузки объявляется (`aria-busy` или текст), не только спиннером.
- [ ] **R-20 P1** Контекст не меняется без предупреждения при фокусе и вводе (3.2.1, 3.2.2).

### Стили

- [ ] **R-21 P0** Размеры в `rem`, `em`, `%`; у контейнеров с текстом `min-height`, не фиксированная высота. Работает при 200% и 320px (1.4.4, 1.4.10, 1.4.12).
- [ ] **R-22 P0** Нет `user-scalable=no` и `maximum-scale=1` (1.4.4).
- [ ] **R-24 P1** Учтены `prefers-reduced-motion`, `forced-colors` и `prefers-contrast`; тема высокого контраста переключается токенами (D-07).
- [ ] **R-25 P1** Текст только для скринридера — через `.sr-only`, не `display:none`. Значимый контент не выводится через `::before/::after`.
- [ ] **R-26 P1** Минимальный размер цели (24px, для основных 44px) задан токеном (2.5.8).

---

## Часть 2. Применимо в React и стеке проекта

### Компоненты

- [ ] **R-02 P0** Заголовки по иерархии; уровень — отдельный проп (`level` или `as`), не привязан к стилю (1.3.1).
- [ ] **R-08 P1** Связи label и описаний — через `useId()`; таблицы данных с `<th scope>` и `<caption>`.
- [ ] **R-12 P0** Модальные окна: фокус внутрь при открытии, удержание внутри, возврат на триггер при закрытии, Esc закрывает, фон `inert`. Предпочтительно нативный `<dialog>` или проверенная headless-библиотека.
- [ ] **R-13 P0** В SPA при смене маршрута обновляется `document.title`, а фокус или объявление переносится на заголовок или `main` (2.4.2, 2.4.3, 4.1.3).
- [ ] **R-23 P0** Цвета только из токенов, проверенных на контраст; `#hex` в компонентах запрещён.

### Проверка в CI и тестах

- [ ] **R-27 P0** `eslint-plugin-jsx-a11y` включён, нарушения блокируют PR.
- [ ] **R-28 P1** Тест axe (`jest-axe`, `vitest-axe` или `@axe-core/playwright`) на каждый компонент.
- [ ] **R-29 P1** Storybook с `addon-a11y`; у компонента есть истории состояний: focus, error, disabled, длинный текст.
- [ ] **R-30 P1** Клавиатурные тесты (`userEvent.tab`, `keyboard`) для modal, menu, tabs. Сложные виджеты берём из React Aria, Radix UI, Headless UI, а не пишем с нуля.
