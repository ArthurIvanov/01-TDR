# Contrast A11y: WCAG & APCA

Плагин для Figma: находит ошибки контраста у текста и иконок и исправляет их в один клик.

## Что умеет

- **Проверка выделения или всей страницы.** Текст (AA и AAA) и иконки (3:1).
- **Два метода:** WCAG 2.x и APCA (Lc). Переключатель в настройках (⚙).
- **Пара слоёв.** Выделите два слоя, плагин сам определит текст и фон.
- **Исправление.** Подбор цвета с сохранением оттенка и насыщенности, ручная правка через пипетку, hex и ползунок светлоты.
- **Массовое исправление** с предпросмотром и одним шагом отмены.
- **Градиентные фоны.** Берётся худшая из опорных точек градиента.
- **Переменные.** Проверка во всех режимах коллекции (светлая и тёмная темы), подбор ближайшего токена, правка самой переменной.
- **Подсветка на макете** красными рамками (по желанию).

## Приватность

Плагин работает локально. Сетевые запросы запрещены в `manifest.json` (`networkAccess: none`), данные файла никуда не отправляются. В `clientStorage` сохраняются только настройки плагина.

## Разработка

```
npm install
npm run build   # компиляция code.ts в code.js
npm run lint
npm run watch
```

В Figma: Plugins → Development → Import plugin from manifest → выберите `manifest.json`.

`code.js` генерируется, править нужно только `code.ts` и `ui.html`.

## Известные ограничения

- Изображения и видео в роли фона проверяются вручную.
- Для градиента учитываются опорные цвета, а не каждая точка.
- Переменные из подключённых библиотек можно привязывать, но нельзя изменять.
- Интерфейс на русском (для ru-локали Figma) и английском (для остальных).
